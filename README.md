# Simple Analytics Connector for Elastic

This project provides a connector between Simple Analytics and Elastic.

## Versions

- **v1**: Exports all data from Simple Analytics to Elastic
- **v2**: Uses the aggregation endpoint for optimized data transfer

## Deploy

Check [developers.google.com/data-studio/...](https://developers.google.com/data-studio/connector/publish-connector) to deploy via Google Forms.
